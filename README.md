# Calendar

_About This Project_

A major project I created was a full stack event planning calendar designed for mobile browsers, used by myself and friends when planning group events.

Users can create groups with different users, and see all upcoming events on a calendar that they have created or were created for a group they are added to. They can additionally view & manage groups or events on dedicated tabs, along with user management and account recovery.

_Tech Stack_
- React
- JavaScript
- CSS Modules
- HTML
- NextJS
- NodeJS
- PostgreSQL

_Development Challenges & Growth_

I had never undertaken any backend development before this, so I had to learn how to build my backend with a REST API, fetching and posting to a database and passing data between my frontend and backend. Although I dedicated time to planning out functionality, database design and component structure before beginning development, the increased scope compared to previous projects, and first implementation of backend work, led to me often refactoring or identifying improvements to implement throughout development.

Additionally, from limitations I found on previous projects which led to frequent prop drilling, I learned how to use React Context to access and update data in components across different sections of my site.

Finally, this was my first project designed as a multi page site, for which I learned NextJS for more powerful React functionality and dynamic page routing.
